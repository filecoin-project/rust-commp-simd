## rust-commp-simd

SIMD-accelerated Filecoin CommP (piece commitment) in Rust, for wasm32 targets

- the Golang side, with its own asm, will be upstreamed directly into [filecoin-project/go-fil-commp-hashash](https://github.com/filecoin-project/go-fil-comp-hashash)
- used by [hugomrdias/commp](https://github.com/hugomrdias/commp)
